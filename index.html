コードの書き方を確認する
HTML・CSS・JavaScript・JSON の基本の書き方を一覧で確認できる。

1. HTML に CSS を適用する2つの方法

学習者は、CSS を別のファイルに書き、link タグで読み込む方法を基本とする。

方法A：<link rel="stylesheet">（推奨）

CSS を style.css という別のファイルに保存し、HTML の head から読み込む。複数のページで同じ CSS を共有できる。

<head>
  <link rel="stylesheet" href="style.css">
</head>

方法B：<style> タグ

HTML の head の中に CSS を直接書く。1つのファイルで完結する。一方、ページが増えると同じ指定を各ページに書く必要が生じる。

<head>
  <style>
    body { background-color: #f0f0f0; }
  </style>
</head>

2. CSS の基本形とセレクタ

CSS は セレクタ { プロパティ: 値; } の形で書く。

  • 要素セレクタ：button { background: blue; }　タグ名で指定する。
  • クラスセレクタ：.box { border: 1px solid black; }　HTML の class="box" に対応する。同じ class は何個でも使える。
  • ID セレクタ：#main { margin: 10px; }　HTML の id="main" に対応する。id は1ページに1つである。

3. JavaScript の読み込みとコメント

HTML は script タグで JavaScript を読み込む。

<!-- 外部ファイルを読み込む -->
<script src="game.js"></script>

<!-- HTML の中に直接書く -->
<script>
  console.log("Hello");
</script>

コメントはコードの中のメモであり、ブラウザは実行の対象から外す。

HTML：<!-- コメント -->
CSS ：/* コメント */
JS  ：// 1行のコメント　/* 複数行のコメント */

4. JSON でデータをまとめる

学習者は、関連する値を { "名前": 値 } の形でまとめ、ドット記法で取り出す。

// 1. まとめる
const data = {
  "music": "apple_tune.mp3",
  "volume": 0.8
};

// 2. 取り出す
const url = data.music;
const vol = data.volume;

// 3. 使う（音声を再生する）
const audio = new Audio(url);
audio.volume = vol;
audio.play();
